** 常用快捷键

1. 从 ~#+end_src~ 快速跳到 ~#+begin_src~ ： ~C-c C-v C-u~
2. ~rg-project~ 的搜索结果窗口
   + 下一个文件 ~S-M-n~
   + 上一个文件 ~S-M-p~
   + 预览当前行 ~C-o~
3. 删除两个单词间的所有空格 ~delete-horizontal-space~ ： ~M-\~
4. 拷贝 minibuffer 的所有内容： ~C-c C-l~
5. 插入换页符 ~^L~ ： ~C-q C-l~
